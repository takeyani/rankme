# UploadDropzone コンポーネント仕様

## 概要

顔写真をアップロードするためのドロップゾーンコンポーネント。
ドラッグ&ドロップとクリックによるファイル選択の両方をサポートする。
RankMeのメインアクション入口であり、ユーザーが最初に操作するコンポーネント。

```typescript
  disabled?: boolean;

  /** ローディング状態（アップロード中） */
  isLoading?: boolean;

  /** カスタムクラス名 */
  className?: string;

  /** プレビュー画像のURL（ファイル選択後に表示） */
  previewUrl?: string | null;

  /** プレビューをクリアするコールバック */
  onClearPreview?: () => void;
}

interface UploadError {
  code: "INVALID_TYPE" | "FILE_TOO_LARGE" | "UPLOAD_FAILED";
  message: string;
}
```

| バリアント | 説明 | 使用場面 |
|-----------|------|---------|
| `default` | 標準のドロップゾーン。ダッシュ枠線、中央にアイコンとテキスト | トップ/アップロード画面 |

## 状態

### default（デフォルト）

- ダッシュ枠線（border-dashed）、ボーダーカラー: #E2E8F0
- 中央に Lucide `Upload` アイコン（24px、セカンダリテキストカラー）
- テキスト: 「写真をドラッグ&ドロップ または クリックして選択」
- サブテキスト: 「JPEG, PNG / 最大5MB」
- 背景: 透明
- 最小高さ: 300px（デスクトップ）、200px（モバイル）
- カーソル: pointer

### hover（ホバー）

- ボーダーカラー: #0891B2（ティールアクセント）に変化
- 背景: #0891B2 の5%透明度
- transition: 150ms ease

### active / drag-over（ドラッグ中）

- ボーダーカラー: #0891B2（ティールアクセント）
- ボーダー幅: 2px（通常1pxから太くなる）
- 背景: #0891B2 の10%透明度
- テキスト: 「ここにドロップ」に変化
- アイコン: スケール 1.1x

### disabled（無効）

- 全体の opacity: 0.5
- カーソル: not-allowed
- ホバー効果なし

### loading（ローディング）

- アイコンがパルスアニメーションに置き換わる
- テキスト: 「アップロード中...」
- ドラッグ&ドロップ無効
- クリック無効

### error（エラー）

- ボーダーカラー: #DC2626（ダンジャー）
- エラーメッセージをドロップゾーン下部に表示
- Lucide `AlertCircle` アイコン + エラーテキスト
- エラーテキストカラー: #DC2626

### with-preview（プレビュー表示）

- ドロップゾーン内にプレビュー画像を表示
- 画像は角丸8pxで表示
- 画像右上に「x」ボタンでクリア可能
- ファイル名とサイズを画像下に表示
- 「診断する」CTAボタンがアクティブ化

## アクセシビリティ要件

- `role="button"` を適用（クリック操作のため）
- `aria-label="顔写真をアップロード"` を設定
- `tabIndex={0}` でキーボードフォーカス可能
- Enter / Space キーでファイル選択ダイアログを開く
- ドラッグ&ドロップ時、`aria-live="polite"` でスクリーンリーダーに状態変化を通知
- エラーメッセージに `role="alert"` を適用
- ファイル選択後、`aria-label` を「選択済み: {ファイル名}」に更新
- フォーカスインジケータ: 2px solid #0891B2 のアウトライン
- タッチターゲットサイズ: 44px以上

## 使用例

```tsx
{/* 基本使用 */}
<UploadDropzone
  onFileSelect={(file) => handleUpload(file)}
  onError={(error) => toast.error(error.message)}
/>

{/* プレビュー付き */}
<UploadDropzone
  onFileSelect={(file) => {
    setPreviewUrl(URL.createObjectURL(file));
    setSelectedFile(file);
  }}
  previewUrl={previewUrl}
  onClearPreview={() => {
    setPreviewUrl(null);
    setSelectedFile(null);
  }}
  onError={(error) => toast.error(error.message)}
/>

{/* ローディング中 */}
<UploadDropzone
  onFileSelect={handleUpload}
  isLoading={isUploading}
/>

{/* コンパクトバリアント（診断レポート画面下部） */}
<UploadDropzone
  onFileSelect={handleReupload}
  className="h-[120px]"
```
