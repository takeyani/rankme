# ScoreDisplay コンポーネント仕様

## 概要

AIが判定したランクスコア（1-10）を大きく視覚的に表示するコンポーネント。
RankMeの診断結果画面における最も重要な要素であり、画面の主役を担う。
スコアカラーシステムに基づき、ランク値に応じた色で数値を表示する。

## 状態

### default（デフォルト）

- スコア数値を中央配置で大きく表示
- フォント: DM Sans 700
- カラー: ランク値に対応するスコアカラー
- `showDenominator={true}` の場合、数値の右に「/10」を小さく添える
- 配置: テキスト中央揃え

### animated（アニメーション付き表示）

- motion/react による表示アニメーション
- 初期状態: opacity: 0, scale: 0.95
- 最終状態: opacity: 1, scale: 1.0
- duration: 200ms
- easing: ease-out
- カウントアップアニメーションは使用しない（静かにフェードインで結果を提示）

### loading（ローディング）

- スコア数値の代わりにスケルトンプレースホルダーを表示
- パルスアニメーション（Tailwind `animate-pulse`）
- スケルトンサイズはバリアントに応じて変化

### error（エラー）

- スコア数値の代わりに「--」を表示
- カラー: セカンダリテキストカラー (#64748B)
- エラーメッセージをスコアの下に赤字で表示

### hover（ホバー、履歴一覧内での使用時）

- opacity: 0.9
- transition: 100ms ease
- カーソル: pointer（詳細画面への遷移リンクの場合）

### disabled（無効）

- opacity: 0.4
- カーソル: default

## アクセシビリティ要件

- `aria-label` でスコアの完全な説明を提供（例: 「診断スコア: 7点（10点満点中）」）
- `aria-live="polite"` でスコアの動的更新をスクリーンリーダーに通知
- カラーだけに依存しない情報伝達: 数値テキスト自体がスコア情報を伝える
- スコアカラーのコントラスト比を検証: 特にランク4-5（黄色系）はライトモード背景でのコントラストに注意し、必要に応じてダーク版カラーを使用
- `tabular-nums` でスコア数値の桁揃えを確保
- ダークモード時、スコアカラーの視認性が維持されることを検証

## 使用例

```tsx
{/* 診断レポート画面 - メイン表示 */}
<ScoreDisplay
  score={7}
  size="lg"
  animated
  showDenominator
  ariaLabel="診断スコア: 7点（10点満点中）"
/>

{/* 履歴一覧 - インライン表示 */}
<ScoreDisplay
  score={5}
  size="md"
  animated={false}
  showDenominator
/>

{/* ラベリング画面 - コンパクト表示 */}
<ScoreDisplay
  score={9}
  size="sm"
  animated={false}
  showDenominator={false}
/>

{/* ローディング中 */}
<div className="flex flex-col items-center gap-4">
  <div className="h-20 w-24 animate-pulse rounded-lg bg-slate-200" />
  <p className="text-sm text-slate-500">AI分析中...</p>
</div>
```

## レイアウト構造

```
+-------------------------------+
|                               |
|          [Score: 7]           |  <- DM Sans 700, 5rem, スコアカラー
|            /10                |  <- DM Sans 400, 1.5rem, セカンダリ
|                               |
+-------------------------------+
```

- スコア数値と分母は同一行にベースライン揃え
- 分母は数値の右下に小さく表示
- 全体をフレックスコンテナで中央配置
