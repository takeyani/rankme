# RankMe UI設計方針

Phase 2 設計ワークフローに基づくUI設計方針。
Phase 1 デザイン要件定義（`docs/requirements/design-requirements.md`）をベースに策定。

---

## 1. Aesthetic Direction（美的方向性）

**Tone**: clinical-professional
**Mood**: serious, trustworthy, minimalist

### デザイン哲学

- RankMeは診断ツールであり、美容アプリではない
- 医療・診断ツールの信頼感を持つUI
- 結果（顔 + スコア）にフォーカスするシンプルなデザイン
- 余白を活用した呼吸感のあるレイアウト
- 装飾ではなく「結果の正確さ」が最も重要であるというメッセージをデザインで伝える

### 差別化（Differentiation）

- 顔に対して大胆にスコアを表示する視覚的インパクト
- 客観性・透明性を伝えるクリーンなデザイン
- プロフェッショナルツールとしての信頼感
- 医療の検査結果レポートのように、シンプルに顔と点数を表示する大胆なUI
- ディープチャコール (#1C2127) とティール (#0891B2) の配色が医療機器のインターフェースを想起させる

### 参照サイト

| サイト名 | 参考ポイント |
|---------|-------------|
| 23andMe | 医療・診断レポートの信頼感のあるUI、クリーンなデータ表示 |
| Apple Health | ヘルスケアデータの視認性の高い表示、ミニマルかつ情報密度の高いレイアウト |
| Linear | プロフェッショナルツールのクリーンなUI、無駄のないインターフェース |

## 2. Typography Guidelines（タイポグラフィ指針）

### 原則

- 特徴的で個性的なフォント選択
- 数字の視認性を最優先（スコア表示がアプリケーションの核）
- 日本語テキストの可読性確保（行間・字間の最適化）
- **禁止**: Inter, Roboto, Arial, Space Grotesk

### フォント選定

| 用途 | フォント | 選定理由 |
|------|---------|---------|
| 見出し/数値 | DM Sans | ジオメトリックでクリーン。数字の視認性が高く、医療・テクノロジー分野で信頼感のある印象 |
| 本文 | Noto Sans JP | 日本語の可読性が最も高く、ウェイトバリエーションが豊富。診断レポートやアドバイスの長文テキストに最適 |

### 適用規則

| 要素 | フォント | ウェイト | サイズ | 用途 |
|------|---------|---------|--------|------|
| ランクスコア | DM Sans | 700 | 5rem | ランク数値表示。画面の主役 |
| ページタイトル (H1) | DM Sans | 700 | 2.5rem | ページ見出し |
| セクションタイトル (H2) | DM Sans | 600 | 2rem | セクション見出し |
| サブセクション (H3) | DM Sans | 600 | 1.5rem | サブ見出し |
| 小見出し (H4) | DM Sans | 600 | 1.25rem | 小見出し |
| 本文 | Noto Sans JP | 400 | 1rem | 一般コンテンツ |
| 本文（大） | Noto Sans JP | 400 | 1.125rem | 強調テキスト |
| キャプション | Noto Sans JP | 400 | 0.875rem | メタデータ、補足 |
| 改善アドバイス | Noto Sans JP | 500 | 0.9375rem | アドバイス項目 |
| 免責テキスト | Noto Sans JP | 400 | 0.75rem | 免責事項 |

### 日本語タイポグラフィ

- Noto Sans JP を全ての日本語テキストに使用
- 本文の行間（line-height）: 1.8
- 本文の字間（letter-spacing）: 0.05em
- 見出しの字間: 0.02em
- `text-balance` を見出しに適用し、行末の不自然な折り返しを防ぐ
- 数値表示には `tabular-nums` を適用し、桁揃えを確保

## 3. Color Guidelines（カラー指針）

### 原則

- Clinical/professional パレット（ディープチャコール + ティールアクセント）
- ランク1-10に対応するスコアカラーグラデーションシステム
- 高コントラストでアクセシビリティ基準（WCAG AA）を満たす
- カラーだけに依存しない情報伝達（テキスト + カラーの併用）

### カラー適用規則

| コンテキスト | カラー | 用途 |
|-------------|--------|------|
| プライマリ背景 | #F8FAFC | ページ背景。やや青みがかったオフホワイトで目に優しい |
| プライマリテキスト | #1E293B | 本文テキスト。高コントラストで読みやすい |
| セカンダリテキスト | #64748B | 補足テキスト、キャプション |
| アクセント | #0891B2 | CTA、リンク、アクティブ状態。ティールの医療的信頼感 |
| プライマリ（濃色） | #1C2127 | ヘッダー、主要セクション背景 |
| サーフェス | #FFFFFF | カード背景、入力フィールド背景 |
| ボーダー | #E2E8F0 | 区切り線、カード枠 |
| サクセス | #16A34A | 成功状態 |
| ダンジャー | #DC2626 | エラー状態 |

### スコアカラーシステム

ランク1-10に対応する直感的なカラーグラデーション:

| ランク | カラー | 視覚印象 |
|--------|--------|---------|
| 1 | #DC2626 | レッド（最低） |
| 2 | #EA580C | オレンジレッド |
| 3 | #D97706 | アンバー |
| 4 | #CA8A04 | ダークイエロー |
| 5 | #A3A30A | イエローグリーン |
| 6 | #65A30D | ライムグリーン |
| 7 | #16A34A | グリーン |
| 8 | #059669 | エメラルド |
| 9 | #0891B2 | ティール |
| 10 | #0284C7 | ブルー（最高） |

> 赤（低）から青（高）へのグラデーション。緑を経由することで、直感的にスコアの良し悪しが伝わる。医療検査の基準値表示と同様のカラーコーディング。

### ダークモード

- システム環境設定を自動検出
- TailwindのdarkバリアントとCSS変数でカラートークン管理

| 用途 | ライト | ダーク |
|------|--------|--------|
| 背景 | #F8FAFC | #0F172A |
| サーフェス | #FFFFFF | #1E293B |
| テキスト（プライマリ） | #1E293B | #F1F5F9 |
| テキスト（セカンダリ） | #64748B | #94A3B8 |
| ボーダー | #E2E8F0 | #334155 |
| アクセント | #0891B2 | #22D3EE |

## 4. Layout Guidelines（レイアウト指針）

### グリッドシステム

- デスクトップ: 12カラムグリッド
- モバイル: 4カラム
- 最大コンテンツ幅: 1280px
- ガター: 24px（デスクトップ）、16px（モバイル）

### スペーシング

- 8px単位システム
- 診断ツールらしい余裕のあるホワイトスペース
- セクション間隔: 48-64px
- コンポーネント間隔: 24-32px

| 名前 | 値 | 用途 |
|------|-----|------|
| xs | 4px | 極小間隔 |
| sm | 8px | 小間隔 |
| md | 16px | 中間隔 |
| lg | 24px | 大間隔 |
| xl | 32px | 特大間隔 |
| 2xl | 48px | セクション間 |
| 3xl | 64px | 大セクション間 |

### Z-Indexスケール

| レイヤー | Z-Index | 用途 |
|---------|---------|------|
| Background | 0 | コンテンツ |
| Dropdown | 10 | メニュー |
| Sticky | 20 | スティッキーヘッダー |
| Modal Overlay | 40 | モーダル背景 |
| Modal | 50 | ダイアログ |
| Toast | 100 | 通知 |

### ビューポート

- `h-dvh` を使用（`h-screen` ではなく動的ビューポート高さ）
- Safe Area対応: `env(safe-area-inset-*)` でiPhone notch/Dynamic Island/home barに対応

### 角丸・シャドウ

| 要素 | 角丸 | シャドウ |
|------|------|---------|
| ボタン | 8px | none |
| カード | 12px | shadow-sm |
| モーダル | 16px | shadow-md |
| 入力フィールド | 8px | none |
| 顔写真エリア | 8px | shadow-sm |
| スコア表示エリア | 12px | none |

> シャドウは控えめに使用する。医療・診断的なUIでは、影よりもボーダーで要素の区切りを表現する方が信頼感がある。

## 5. Motion Guidelines（モーション指針）

### 原則

- 全てのインタラクションは**200ms以下**
- **Compositorプロパティのみ**使用: transform, opacity
- レイアウトプロパティ（width, height, margin, padding等）のアニメーションは禁止
- 診断ツールとしての冷静さを維持する控えめな演出

### 画面別アニメーション

| 画面/要素 | アニメーション | duration | イージング |
|-----------|---------------|----------|-----------|
| スコアリビール | フェードイン + 軽いスケール (0.95 -> 1.0) | 200ms | ease-out |
| ページ遷移 | サブトルフェード | 150ms | ease-in-out |
| カード表示 | スタガーフェードイン | 各100ms、delay 50ms | ease-out |
| ボタンホバー | opacity変化 (1.0 -> 0.9) | 100ms | ease |
| アップロードドロップ | ボーダーカラー変化 | 150ms | ease |
| ローディング | パルスアニメーション | 1500ms loop | ease-in-out |

### 禁止アニメーション

- バウンス効果
- 3Dトランスフォーム
- パーティクルエフェクト
- レイアウトプロパティのアニメーション
- 200msを超えるインタラクションアニメーション
- カウントアップアニメーション（静かにフェードインで結果を提示する）
- 複雑なキーフレームシーケンス
- `will-change` の乱用（必要な箇所のみ限定的に使用）
- `blur` フィルタの過度な使用（パフォーマンス低下の原因）

## 6. Component-Specific Guidelines（コンポーネント別指針）

### アップロードエリア

- 大きなドロップゾーン（デスクトップで最小高さ300px）
- ダッシュ枠線、ホバー時にティールアクセントに変化
- ドラッグ&ドロップ + クリックでファイル選択
- ファイルタイプバリデーション: JPEG, PNG
- ファイルサイズバリデーション: 最大5MB
- 選択時にプレビュー表示
- 中央にLucideの `Upload` アイコン + 説明テキスト

### スコア表示

- 中央配置、大きな数字（DM Sans 700 / 5rem）
- ランク値に基づくスコアカラー表示
- 数字の横に「/10」を小さいフォントで添える
- motion/reactによるフェードイン + 微細スケールアニメーション
- 明確な視覚階層: スコア > アドバイス > 免責テキスト
- 顔写真とスコアは分離表示（オーバーレイしない）

### アドバイスカード

- カード形式レイアウト
- アイコン + タイトル + 説明文の構成
- スキャンしやすい箇条書きポイント
- プロフェッショナルで非判断的なトーン
- 3-5項目をスタガーフェードインで表示

### 履歴一覧

- デスクトップ: クリーンなテーブル表示（shadcn/ui DataTable活用）
- モバイル: カードリスト表示
- 日付フォーマット: YYYY/MM/DD
- ランクにスコアカラーインジケータ付き
- クリックで詳細展開

### ラベリングインターフェース

- 効率的なグリッドレイアウト
- クイックランク選択（1-10ボタン）
- 一括選択・操作機能
- 画像のホバー/クリックでズーム
- キーボードショートカット対応

### 免責テキスト

- 控えめだが明確に表示
- スコア表示の下に配置
- フォントサイズ: 0.75rem
- セカンダリテキストカラー
- 内容: 「本判定は、選別済み画像データとの類似度および傾向分析に基づく客観的結果です。個人の価値や魅力を断定するものではありません。」

## 9. Accessibility（アクセシビリティ指針）

### 基準

| 項目 | 基準 |
|------|------|
| WCAG準拠レベル | AA |
| コントラスト比 | 4.5:1以上（通常テキスト） |
| タッチターゲット | 44px以上 |

### 要件

- 全てのインタラクティブ要素: キーボードアクセシブル
- 全ての画像: `alt` テキスト必須
- スコア表示: `aria-label` でフル説明を付与
- `aria-live` でスコアの動的更新をスクリーンリーダーに通知
- カラーだけに依存しない情報伝達（テキスト + カラーの併用）
- フォーカスインジケータを明確に表示
- スキップナビゲーションリンクを設置
- Radix UIプリミティブ（shadcn/ui経由）のアクセシビリティ機能を活用

### コントラスト比の注意点

- ディープチャコール (#1C2127) 上のティール (#0891B2) テキストのコントラスト比を検証し、AA基準を満たすこと
- スコアカラー（特に黄色系のランク4-5）はテキスト使用時にコントラスト比に注意し、必要に応じてダーク版カラーを使用する

## 10. 画面別デザイン方針

### トップ/アップロード画面

- **ヘッダー**: シンプルに「RankMe」のロゴ/タイトルを配置。サブタイトルに「プロスカウト基準AI診断」等の説明文
- **アップロードエリア**: 画面中央に大きく配置。ダッシュ枠線のドロップゾーン
- **CTA**: 「診断する」ボタン。アクセントカラー（ティール）背景、白テキスト
- **ナビゲーション**: 「履歴を見る」リンクをヘッダーまたはアップロードエリア下に配置
- **トーン**: 清潔感があり、シンプル。余計な装飾は一切なし

### 診断中画面

- **ローディング**: 控えめで専門的。パルスアニメーションまたはスケルトンUI
- **プログレスインジケータ**: 「AI分析中...」のテキスト + シンプルなプログレスバー
- **トーン**: 落ち着いた待機画面。焦らせない、信頼感のある表現

### 診断レポート画面

- **レイアウト**: 顔写真 + ランク数値を画面の最上部に大きく配置
- **スコア表示**: DM Sans 700/5rem。スコアカラーで表示。数字の横に「/10」を添える
- **改善アドバイス**: カード形式で3-5項目
- **免責テキスト**: スコア表示の下に小さいフォントで配置

### 履歴一覧画面

- テーブル/カードリスト表示
- 日付、ランク（スコアカラー付き）、サムネイルの表示
- ソート: 日付順（デフォルト）

### ラベリング管理画面

- グリッド表示。画像 + ランクセレクター（1-10）
- 複数選択 + 一括ランク設定
- 機能性・効率性を優先

### レスポンシブ方針

| 画面 | Mobile | Tablet | Desktop |
|------|--------|--------|---------|
| トップ/アップロード | シングルカラム | シングルカラム（中央寄せ） | 中央配置、max-width制約 |
| 診断レポート | 縦積み: 顔写真 -> スコア -> アドバイス | 2カラム: 顔写真+スコア / アドバイス | 2カラム + サイドパネル |
| 履歴一覧 | カードリスト | 2カラムグリッド | テーブル表示 |
| ラベリング管理 | カードリスト + スコア入力 | 3カラムグリッド | 4-6カラムグリッド + サイドパネル |
